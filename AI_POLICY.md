# AI policy

AI tools are welcome here. Most of this fork was written with Claude, and every change still went through review, tests and a human decision. Your contribution is held to the same rules, whoever or whatever wrote it.

## You answer for it

- You are responsible for every line, test and claim in your issue or pull request.
- You understand the change and can explain it in your own words when a reviewer asks. "The AI wrote it" is not an answer.
- You open the pull request and you answer the review yourself. Replies posted by a bot or pasted from a model without reading them are not.

## Prove it

- A fix comes with a test that fails without it and passes with it, as [CONTRIBUTING.md](CONTRIBUTING.md) describes. Run it yourself; don't paste output you didn't see.
- A number, a timing or an "always" in your description is measured, or it says plainly that it isn't.
- A bug report has steps you ran yourself and the smallest code that shows the bug.

## Say you used it

- Name the tool in a `Co-Authored-By` trailer on the commit, such as `Co-Authored-By: Claude <noreply@anthropic.com>`, or say so in the pull request.

## Keep it small

- One issue per pull request. Don't send changes generated across the whole codebase at once.
- Don't file issues in bulk. Each one needs its own reproduction.

## What the maintainer does

AI-assisted contributions are reviewed like any other. A pull request or issue that doesn't follow this policy may be closed with a pointer to it.
